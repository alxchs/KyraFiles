## 1. Verificação das Afirmações do Plan

### 1.1 Formato que "Copiar" Deixa na Área de Transferência
- **Status:** **CONFIRMED**
- **Comando:**
  Inspeção de `src/Files.App/Helpers/TransferHelpers.cs:59-62` e `CopyItemPathAction.cs:48-52`.
- **Evidência no código:**
  - Quando itens são copiados via `CopyItemAction`: `TransferHelpers.cs` popula o `DataPackage` com `dataPackage.SetStorageItems(items, false)` sob o formato padrão do Windows `StandardDataFormats.StorageItems`.
  - Quando o caminho é copiado via `CopyItemPathAction`: grava texto plano formatado via `dataPackage.SetText(path)` (`StandardDataFormats.Text`).
  - Para o cenário AC-2 ("Comparar com o copiado"), o leitor deve inspecionar ambos os formatos no `Clipboard.GetContent()`: recuperar primeiro os `StorageItems` (se houver 1 item copiado) ou fallback para `GetTextAsync()` caso contenha um caminho de arquivo válido no disco.

### 1.2 Como `IDevToolsSettingsService` Guarda Configurações e como Acrescentar Lista
- **Status:** **CONFIRMED**
- **Comando:**
  Inspeção de `src/Files.App/Services/Settings/DevToolsSettingsService.cs:6-39`.
- **Evidência no código:**
  A classe `DevToolsSettingsService` herda de `BaseObservableJsonSettings`.
  A serialização e persistência de propriedades é feita de forma declarativa e fortemente tipada através dos métodos `Get<T>()` e `Set<T>()`. Para adicionar a lista de ferramentas de diff configuradas pelo usuário (`List<DiffToolModel>`), basta declarar a propriedade na interface `IDevToolsSettingsService` e expô-la em `DevToolsSettingsService` usando `Get<List<DiffToolModel>>(() => new())` e `Set(value)`.
