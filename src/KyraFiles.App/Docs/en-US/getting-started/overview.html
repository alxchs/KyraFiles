Overview

Files is a modern file manager designed to help users organize their files and folders with agility, elegance, and complete control. Built with WinUI 3 and native Windows 11 Fluent Design.

Key Platform Highlights

  • Robust Multitasking: Full tab navigation, Dual Pane view, and intuitive drag & drop file operations.
  • File Tags: Color-code and organize files with metadata preserved in NTFS Alternate Data Streams (ADS).
  • Fluent Design & Themes: Native Mica backdrop support, automatic Dark/Light mode, and compact density.
  • Git Integration: Switch branches, check status of tracked files, and commit directly from the file manager.
  • KyraFiles Exclusives: Miller Columns with independent resize, external F3 search, and strict memory containment.
