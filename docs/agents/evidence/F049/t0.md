## 1. Verificação das Afirmações do Plan

### 1.1 O que `ListedItem.IsSymLink` marca de fato
- **Status:** **CONFIRMED com esclarecimento técnico**
- **Comando:**
  ```powershell
  git grep -n "IsSymLink =" src/
  ```
- **Saída:**
  ```text
  src/Files.App/Utils/Storage/Enumerators/Win32StorageEnumerator.cs:330: IsSymLink = true,
  src/Files.App/Utils/Storage/Enumerators/Win32StorageEnumerator.cs:352: IsSymLink = true
  ```
- **Evidência no código (`Win32StorageEnumerator.cs:305-307`):**
  ```csharp
  bool isReparsePoint = ((FileAttributes)findData.dwFileAttributes & FileAttributes.ReparsePoint) == FileAttributes.ReparsePoint;
  bool isSymlink = isReparsePoint && findData.dwReserved0 == Win32PInvoke.IO_REPARSE_TAG_SYMLINK;
  ```
  O enumerador atual só seta `IsSymLink = true` se `dwReserved0 == IO_REPARSE_TAG_SYMLINK`.
  Uma junction (`IO_REPARSE_TAG_MOUNT_POINT = 0xA0000003`) **não** é marcada como `IsSymLink`; é tratada como pasta comum (`FolderItem`). A F049 precisará distinguir os tags de reparse point (`IO_REPARSE_TAG_SYMLINK` vs `IO_REPARSE_TAG_MOUNT_POINT`).

### 1.6 Criação de Junctions no Windows
- **Status:** **CONFIRMED**
- **Técnica:**
  - Symlinks: `.NET` `File.CreateSymbolicLink` / `Directory.CreateSymbolicLink`.
  - Hardlinks: Win32 `CreateHardLinkW`.
