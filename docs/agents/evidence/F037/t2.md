## 1. Implementação
- **Arquivo:** `src\KyraFiles.App\Helpers\RenameRuleEngine.cs`
- **Componentes:**
  - `IRenameRule`: interface pura para composição de regras de renomeação.
  - `FindReplaceRule`: texto exato ou regex (com timeout de 500ms para mitigar ReDoS), suporte a case-sensitive e opção de aplicar ou não na extensão.
  - `NumberingRule`: numeração sequencial (prefixo, sufixo ou substituição completa), passo, padding com zeros (`001`, `002`), separador customizado.
  - `CaseTransformRule`: maiúsculas, minúsculas, título (`TitleCase`), capitalizar primeira letra.
  - `DateRule`: data de modificação, criação ou data atual, com formatação flexível (`yyyy-MM-dd`, etc.) e recuo seguro.
  - `ReplaceSpacesRule`: troca de espaços por separador (`_`, `-`, etc.).
  - `RenameRuleEngine.GeneratePreview`: geração de pré-visualização completa com detecção de:
    - Colisões entre itens do mesmo lote.
    - Colisões contra arquivos existentes no disco.
    - Caracteres proibidos no Windows (`\ / : * ? " < > |`).
    - Nomes terminados em ponto ou espaço.
    - Nomes de dispositivos reservados do Windows (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`).
    - Excesso de tamanho de caminho (`MAX_PATH >= 260`).
