Modos de Exibição & Layout

O Files oferece diferentes modos de visualização adaptáveis para qualquer tipo de trabalho ou preferências visuais do usuário:

Modos Disponíveis

  • Detalhes: Visualização em tabela com colunas personalizáveis (Tamanho, Data de Modificação, Tipo, Tags, Autor do Git, Hash do Commit, etc.). No Files Custom, cada coluna tem redimensionamento e persistência independentes.
  • Colunas (Miller Columns): Navegação vertical em cascata inspirada no Mac Finder e no OneCommander. Cada pasta aberta expande uma nova coluna para a direita, permitindo rastrear o caminho completo da árvore sem perder o contexto.
  • Grade (Grid): Ícones amplos e espaçados com visualização rica de miniaturas, ideal para pastas de fotos, vídeos e downloads.
  • Lista: Visão compacta e rápida com apenas o ícone e nome do arquivo, permitindo navegar em diretórios com milhares de itens com consumo mínimo de recursos.

Atalhos Rápidos de Layout

Você pode alternar entre os modos a qualquer momento usando a barra inferior de layout ou os atalhos:

  • Ctrl + Shift + 1: Modo Detalhes
  • Ctrl + Shift + 2: Modo Lista
  • Ctrl + Shift + 3: Modo Cartões
  • Ctrl + Shift + 4: Modo Grade
  • Ctrl + Shift + 5: Modo Colunas (Miller Columns)
