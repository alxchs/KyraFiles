Win + E e explorer.exe abrem no Files; F3 abre o Agent Ransack

Com o Files aberto ou em segundo plano, as janelas novas do Explorer passam para o Files sem chegar a aparecer. O F3 abre o Agent Ransack na pasta atual, e os nomes das colunas extras seguem o idioma do app.

Para valer depois de reiniciar o PC

O Files precisa estar rodando. Ligue Configurações > Avançado > Abrir o Files ao iniciar o Windows; nesta máquina essa opção está desligada. Com o Files fechado, o Win + E abre o Explorer.

Como testar

  1. Feche o Files Dev e rode .\Open-FilesDev.ps1.
  2. Aperte Win + E: deve abrir o Files em "Este Computador".
  3. Win + R, digite explorer C:\Windows: deve abrir no Files.
  4. Numa pasta do Files, aperte F3: o Agent Ransack abre nela.
  5. Botão direito no cabeçalho "Nome" > "More...": nomes no idioma do app.
