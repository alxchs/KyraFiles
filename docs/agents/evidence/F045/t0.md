### 1.2 O que `PowerShellExecutionOptions` Permite
- **Status:** **CONFIRMED**
- **Comando:**
  Inspeção de `src/Files.App/Data/Enums/PowerShellExecutionOptions.cs` e `src/Files.App/Helpers/Win32/Win32Helper.Storage.cs:826-850`.
- **Evidência no código:**
  ```csharp
  [Flags]
  public enum PowerShellExecutionOptions
  {
      None = 0x0,
      Hidden = 0x1,
      Elevated = 0x2
  }
  ```
  A implementação existente (`Win32Helper.RunPowershellCommandAsync`) apenas inicia `powershell.exe` em segundo plano e retorna um `Task<bool>`. Não redireciona nem captura stdout/stderr, não provê código de saída detalhado nem cancelamento via CancellationToken. O novo executor (`Process` runner próprio da F045) é fundamental para atender aos requisitos de exibição de saída (AC-5) e cancelamento (AC-6).
