Paleta de Comandos (Command Palette)

A Paleta de Comandos é um centro unificado de busca e execução de ações. Sem tirar as mãos do teclado, você pode disparar comandos, alternar configurações, abrir utilitários ou navegar pelo sistema.

Como abrir

Pressione Ctrl + Shift + P ou digite na barra de endereço (Omnibar). Digite qualquer palavra do comando (ex: "terminal", "ocultos", "git", "colunas") e pressione Enter para executar imediatamente.

Comandos Populares

  • Alternar arquivos ocultos: Ctrl + H
  • Alternar extensões de arquivos: Mostra ou oculta as extensões (.exe, .txt, etc.).
  • Abrir Terminal integrado / PowerShell: Abre o console moderno na pasta atual.
  • Compactar / Descompactar: Cria arquivos compactados 7z ou ZIP com um comando.
