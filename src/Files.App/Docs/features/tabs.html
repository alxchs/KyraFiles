Abas & Multitarefa

O recurso de abas no Files permite trabalhar em várias pastas simultaneamente sem poluir a sua área de trabalho com janelas espalhadas. Você pode alternar rapidamente entre diferentes diretórios clicando na aba correspondente ou usando atalhos de teclado.

Como abrir novas abas

Você pode adicionar uma nova aba clicando no botão + na barra de títulos ou usando o atalho Ctrl + T. Para abrir uma pasta existente diretamente em uma nova aba, clique sobre ela com o botão do meio do mouse (scroll) ou selecione Abrir em nova aba no menu de contexto.

Arrastar arquivos entre abas

Para mover ou copiar arquivos entre abas, basta arrastar os itens selecionados e repousar o cursor sobre a aba de destino. A aba se abrirá automaticamente para você soltar os arquivos na pasta desejada.

Atalhos de Abas

Ctrl + Shift + TReabrir última aba fechada

Ctrl + Shift + KDuplicar aba atual
