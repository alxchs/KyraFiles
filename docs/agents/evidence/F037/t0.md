  ```csharp
  case FileOperationType.Rename: // Opposite: Restore original item names
      var renamedItems = history.Destination;
      if (!IsHistoryNull(history.Source) && !IsHistoryNull(renamedItems))
      {
          NameCollisionOption collision = NameCollisionOption.GenerateUniqueName;
          for (int i = 0; i < renamedItems.Count; i++)

O mesmo ocorre para o `Redo`. Um único objeto `StorageHistory` contendo múltiplos itens renomeados funciona de forma nativa e atômica.

### 1.2 Significado dos Dois Últimos Parâmetros de `RenameAsync`
- **Status:** **CONFIRMED**
- **Comando:**
  ```powershell
  git grep -n "RenameAsync" src/Files.App/Utils/Storage/Operations/IFilesystemHelpers.cs
  ```
- **Assinatura no código (`IFilesystemHelpers.cs:250` e `261`):**
  ```csharp
  Task<ReturnResult> RenameAsync(
      IStorageItemWithPath source,
      string newName,
      NameCollisionOption collision,
      bool registerHistory,
      bool showExtensionDialog = true);
  ```
  Na chamada `RenameAsync(item, ..., NameCollisionOption.GenerateUniqueName, true, false)`:
  - **4º parâmetro (`true`):** `registerHistory` — se `true`, registra cada item na pilha de histórico de desfazer/refazer.
  - **5º parâmetro (`false`):** `showExtensionDialog` — se `false`, suprime o diálogo individual de confirmação de alteração de extensão de arquivo (evitando múltiplos popups intrusivos durante a operação em lote).
