- **Status:** **CONFIRMED**
- **Comando:**
  ```powershell
  git grep -n "Keys.Space" src/KyraFiles.App/Actions/
  ```
- **Evidência no código (`LaunchPreviewPopupAction.cs:22-28`):**
  ```csharp
  public HotKey HotKey
      => new(Keys.Space);

  public bool IsExecutable =>
      context.SelectedItems.Count == 1 &&
      (!context.ShellPage?.SlimContentPage?.IsRenamingItem ?? false);
  ```
  A ação `LaunchPreviewPopupAction` declara `HotKey => new(Keys.Space)`.
  A condição `IsExecutable` já verifica se `IsRenamingItem` é falso, garantindo que em modo de renomeação o espaço não acione o popup.

### 1.2 Por que os Layouts Tratam a Tecla Espaço (`e.Handled = true`)
- **Status:** **CONFIRMED**
- **Comando:**
  ```powershell
  git grep -n "Key == VirtualKey.Space" src/KyraFiles.App/Views/Layouts/
  ```
- **Evidência no código (`DetailsLayoutPage.xaml.cs:707`, `GridLayoutPage.xaml.cs:633`, `ColumnLayoutPage.xaml.cs:484`):**
  Nos três layouts, o evento `ItemManipulationModel_KeyDown` intercepta `VirtualKey.Space` e define `e.Handled = true` para suprimir o comportamento padrão dos controles WinUI `ListViewBase`/`GridView` (que selecionam/deselecionam ou rolam a lista). O teclado acelerador do sistema de comandos do KyraFiles captura o `Keys.Space` da ação.

### 1.4 Análise de `LaunchPreviewPopupAction` e Troca de Provedor
- **Status:** **CONFIRMED**
- **Evidência no código (`LaunchPreviewPopupAction.cs:38-78`, `PreviewPopupService.cs:9-20`):**
  - Ao apertar Espaço, `ExecuteAsync` obtém o provedor via `previewPopupService.GetProviderAsync()` e chama `provider.TogglePreviewPopupAsync(itemPath)`.
  - Ao navegar com as setas, `SwitchPopupPreviewAsync` (com debounce de 150 ms e throttle de 5s na checagem de provedor) chama `provider.SwitchPreviewAsync(itemPath)`.
  - `PreviewPopupService.cs` testa `QuickLookProvider`, `SeerProProvider`, `PowerToysPeekProvider` e retorna `null` caso nenhum esteja presente.
  - O `BuiltInPreviewProvider` embutido se encaixará exatamente como o fallback final quando nenhum externo estiver ativo.
