Organização com Tags

Tags são etiquetas coloridas que você pode associar a qualquer arquivo ou pasta para facilitar a organização, triagem e busca visual rápida.

Como associar tags

  • Clique com o botão direito nos itens e abra o submenu Editar tags.
  • Selecione uma ou mais tags na lista.
  • No painel de detalhes (Ctrl + Alt + D), clique no botão de tags para editar rapidamente.

Buscar por tags

Na caixa de busca ou na barra de endereços, digite tag:NomeDaTag (por exemplo, tag:Trabalho ou tag:Importante) para filtrar instantaneamente todos os itens marcados.
