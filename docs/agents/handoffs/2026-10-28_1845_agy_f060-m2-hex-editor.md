## 2. Roteiro de Execução da Prova de Tela (M2-T5)

A prova de tela deve ser executada após as 23:59, sem roubo de foco do usuário, via automação UI Automation / script PowerShell.

### 2.1 Pré-condições e Ambiente Isolado
1. Criar pasta temporária isolada de teste:
   `$lab = "$env:TEMP\agy\$(New-Guid)\f060_m2_lab"`
   `New-Item -ItemType Directory -Path $lab -Force`
2. Gerar arquivo de teste de 100 MB com padrão determinístico:
   `$hexFile = Join-Path $lab "amostra.bin"`
   `$data = New-Object byte[] (100 * 1024 * 1024); for ($i=0; $i -lt $data.Length; $i++) { $data[$i] = [byte]($i % 256) }; [IO.File]::WriteAllBytes($hexFile, $data)`
   `$hashInicial = (Get-FileHash $hexFile -Algorithm SHA256).Hash`

### 2.2 Passo a Passo dos Cenários de Tela

#### Cenário 1: Abertura e Virtualização Instantânea (M2-AC-1)
1. Navegar na instância de teste para `$lab`.
2. Selecionar `amostra.bin`.
3. Clicar com botão direito -> "Open in Hex Editor" (ou acionar via menu/atalho).
4. **Verificação:** A janela `HexEditorWindow` abre em < 500 ms.
   - Grade exibe as primeiras 30 linhas.
   - Barra de status indica offset `0x00000000`, tamanho `100 MB` e `Modified: 0`.
   - Medição de WorkingSet do processo não sofre salto de 100 MB (mantém-se O(1)).

#### Cenário 2: Navegação e Deslocamento (M2-AC-2 e M2-AC-3)
1. Pressionar `Ctrl+G` (Go to Offset).
2. No diálogo de prompt, digitar `0x00A00000` (10 MB adiante).
3. Confirmar "Go".
4. **Verificação:** A grade rola instantaneamente para o offset `00A00000`.
   - Clicar sobre um byte na coluna hexadecimal (ex.: byte no offset `00A00004`).
   - Conferir que o caractere correspondente na coluna ASCII é realçado simultaneamente.
   - Tentar digitar caracteres na coluna ASCII: confirmar que a coluna ASCII é estritamente somente-leitura.

#### Cenário 3: Edição in-place e Salvamento Seguro (M2-AC-4 e M2-AC-5)
1. No offset atual, digitar os dígitos hexadecimais `F` e `F` (alterando o byte para `0xFF`).
2. Digitar `A` e `B` no próximo byte.
3. Observar status: `Modified: 2`.
4. Pressionar `Ctrl+Z`: modified count recua para 1 e o byte volta ao valor anterior.
5. Pressionar `Ctrl+Y`: o byte volta a `0xAB`.
6. Pressionar `Ctrl+S` para salvar.
7. Fechar a janela `HexEditorWindow`.
8. **Verificação Externa:**
   - Conferir que apenas os bytes nos offsets editados foram alterados:
     `(Get-FileHash $hexFile -Algorithm SHA256).Hash -ne $hashInicial` (diferente).
   - Inspecionar diretamente os bytes do arquivo para confirmar que nenhum byte fora dos editados foi tocado.
   - Confirmar que nenhum arquivo `.journal` residual permaneceu na pasta `$lab`.

#### Cenário 4: Controle Negativo — Arquivo Alterado Externamente (M2-AC-6)
1. Reabrir `amostra.bin` no editor hexadecimal.
2. Alterar 1 byte no editor (não salvar ainda).
3. Externamente via PowerShell, tocar a data ou alterar um byte no arquivo:
   `[IO.File]::SetLastWriteTimeUtc($hexFile, [DateTime]::UtcNow.AddHours(1))`
4. No editor hexadecimal, pressionar `Ctrl+S`.
5. **Verificação esperada:** O editor exibe mensagem de alerta informando que o arquivo foi modificado por outro processo (`File identity changed`) e recusa a gravação em disco para evitar corrupção de dados concorrente.

#### Cenário 5: Controle Negativo — Arquivo Somente Leitura (M2-AC-7)
1. Marcar o arquivo como Read-Only:
   `Set-ItemProperty $hexFile -Name IsReadOnly -Value $true`
2. Tentar salvar alteração no editor.
3. **Verificação esperada:** O editor exibe mensagem amigável de erro informando permissão negada e confirmando que o arquivo original permaneceu intacto.
