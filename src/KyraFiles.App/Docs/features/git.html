Integração com Repositórios Git

O Files possui integração nativa e profunda com o Git, projetada para desenvolvedores e equipes de software que desejam acompanhar o status de seus projetos diretamente pelo gerenciador de arquivos.

Informações na Barra de Status

Ao abrir qualquer pasta que contenha um repositório Git (.git), a Barra de Status inferior exibirá:

  • Nome da branch atual com menu de alternância e criação de branches.
  • Contador de commits locais e remotos para envio (push) e recebimento (pull).
  • Status de sincronização em tempo real.

Colunas Git no Modo Detalhes

No modo Detalhes, você pode ativar as colunas especiais do Git clicando com o botão direito nos cabeçalhos das colunas:

  • Status Git: Modificado, Novo, Ignorado ou Sincronizado.
  • Último Commit: Mensagem do último commit relacionado ao arquivo.
  • Autor do Commit: Nome do autor da alteração.
  • Hash do Commit: Identificador curto do commit.
